## 3.1. Интерполяционные многочлены Лагранжа и Ньютона

Функция `f(x) = tg(x) + x`, заданная точка `x* = 3π/16`. В JSON используется запись `tan(x) + x`.

- Набор а: `0, π/8, 2π/8, 3π/8`.
- Набор б: `0, π/8, π/3, 3π/8`.

Метод Лагранжа вычисляет сумму `y_i ∏_{j≠i}(x − x_j)/(x_i − x_j)`. Для метода Ньютона строится треугольная таблица разделённых разностей: `f[x_i,…,x_{i+k}] = (f[x_{i+1},…,x_{i+k}] − f[x_i,…,x_{i+k−1}])/(x_{i+k} − x_i)`. Первая строка задаёт коэффициенты Ньютона, значение рассчитывается во вложенной форме.

Для каждого набора выводятся исходные `x_i, y_i`, базисная и раскрытая формы Лагранжа, таблица разделённых разностей, форма Ньютона и её раскрытие, оба значения в `x*`, точное значение функции, абсолютная погрешность каждого метода, разность результатов и её модуль. Коэффициенты раскрытых форм строятся отдельно для каждого метода.

| Набор | L(x*) | N(x*) | f(x*) | Абсолютная погрешность |
| --- | --- | --- | --- | --- |
| а | 1.233655403735 | 1.233655403735 | 1.257227260467 | 0.023571856733 |
| б | 1.174299451376 | 1.174299451376 | 1.257227260467 | 0.082927809091 |

Многочлены с округлёнными коэффициентами:

```text
а: L(x) = N(x) = 1.807748901982*x³ − 1.573417063598*x² + 2.393888009302*x
б: L(x) = N(x) = 2.678977450556*x³ − 2.941939667497*x² + 2.796951186678*x
```

Для одинаковых узлов Лагранж и Ньютон представляют один многочлен. Различие результатов до `4.44e-16` связано с округлением в `float`. Набор а даёт меньшую погрешность в заданной точке.

[График набора а](graphs/interpolation_a.svg) · [График набора б](graphs/interpolation_b.svg) · [Полный вывод](results/1.txt)

Каждый график содержит исходную функцию, обе формы интерполяционного многочлена, узлы, вертикальную линию `x*`, точное и интерполированное значения в этой точке. Линия Ньютона пунктирная, чтобы обе совпадающие кривые были видны.

## 3.2. Натуральный кубический сплайн

```text
x: 0.0, 0.9,     1.8,    2.7,    3.6
y: 0.0, 0.72235, 1.5609, 2.8459, 7.7275
x* = 1.5
```

Для участка `[x_i, x_{i+1}]` используется форма `S_i(x) = a_i + b_i*t + c_i*t² + d_i*t³`, где `t = x − x_i`. Здесь `c_i = S''(x_i)/2`. При `h_i = x_{i+1} − x_i` внутренние коэффициенты находятся прогонкой из системы:

```text
h_(i−1)*c_(i−1) + 2*(h_(i−1)+h_i)*c_i + h_i*c_(i+1)
    = 3*((y_(i+1)−y_i)/h_i − (y_i−y_(i−1))/h_(i−1))
c_0 = c_4 = 0
```

Остальные коэффициенты: `a_i = y_i`, `b_i = (y_{i+1} − y_i)/h_i − h_i*(2c_i + c_{i+1})/3`, `d_i = (c_{i+1} − c_i)/(3h_i)`.

Программа выводит коэффициенты и формулу каждого участка, интервалы их действия, `S(x*)`, номер выбранного интервала, проверку всех узлов и вторых производных на концах. Дополнительно проверяются непрерывность `S`, `S'`, `S''` во внутренних узлах.

Результат: **`S(1.5) = 1.313558994709`**, участок **№ 2**, `[0.9, 1.8)`. Нумерация участков в выводе начинается с 1, исходных узлов — с 0. Внутренний узел относится к участку справа, правый конец всего отрезка — к последнему участку.

Сплайн проходит через все узлы с погрешностью округления не более `8.9e-16`; вторые производные на концах равны нулю. Независимая проверка в рациональной арифметике даёт `S(1.5) = 4965253/3780000`.

[График сплайна](graphs/spline.svg) · [Полный вывод и таблица коэффициентов](results/2.txt)

На графике каждый участок выделен своим цветом, отмечены исходные узлы и точка `(x*, S(x*))`.

## 3.3. Метод наименьших квадратов

Исходные данные варианта 14:

```text
x: -0.9,     0.0, 0.9,    1.8,    2.7,    3.6
y: -1.2689,  0.0, 1.2689, 2.6541, 4.4856, 9.9138
```

Для каждой степени m=1,2,3 строится нормальная система `A*a=b`:
`A[j,k]=Σ x_i^(j+k)`, `b[j]=Σ y_i*x_i^j`, j,k=0..m. Она решается
собственной реализацией метода Гаусса с масштабированным выбором главного
элемента. В вывод входят сама система, все коэффициенты, явные многочлены,
их значения во всех шести точках, SSE и MSE. Коэффициенты хранятся от
свободного члена к старшему, значение вычисляется схемой Горнера.

```text
P₁(x) = 2.246206349206*x - 0.190128571429
P₂(x) = 0.508088624339*x² + 0.874367063492*x - 0.464496428571
P₃(x) = 0.240988416400*x³ - 0.467914462081*x² + 1.206208112875*x + 0.273361904762
```

| Степень | SSE = Σ(P(xᵢ)-yᵢ)² | MSE = SSE / 6 |
| --- | --- | --- |
| 1 | 8.679034651429 | 1.446505775238 |
| 2 | 2.355706084643 | 0.392617680774 |
| 3 | 0.355741072143 | 0.059290178690 |

По MSE на заданных точках лучше всего приближает данные **многочлен третьей
степени**. Делитель MSE равен числу исходных точек N=6, а не числу степеней
свободы `N-m-1`. Это сравнение ошибки на исходной таблице, не на новых данных.

[График МНК](graphs/least_squares.svg) · [Полный вывод](results/3.txt).
На одном графике показаны три многочлена и исходные данные отдельными точками.

Нормальные уравнения используются по условию методички. Для таблиц с большими
координатами или высокой степенью они могут быть плохо обусловлены; реализация
обнаруживает слишком малый ведущий элемент и сообщает об ошибке. Для данного
варианта коэффициенты и ошибки сверены независимым способом.

## 3.4. Численное дифференцирование

В `inputs/4.json` нужно заполнить `x`, `y`, `x_star`. Требуются минимум три различных узла, расположенных по возрастанию, и точка внутри отрезка таблицы.

Производные рассчитываются по квадратичному интерполянту на трёх соседних узлах; равномерность сетки не требуется. Выбирается тройка с минимальным максимальным расстоянием до `x*`, при равенстве — с минимальной суммой расстояний, затем с меньшим начальным индексом. Программа сообщает выбранные индексы и все три пары `(x_i,y_i)`.

```text
d_01  = (y_(i+1) − y_i)/(x_(i+1) − x_i)
d_12  = (y_(i+2) − y_(i+1))/(x_(i+2) − x_(i+1))
d_012 = (d_12 − d_01)/(x_(i+2) − x_i)
f'(x*)  ≈ d_01 + d_012*(2*x* − x_i − x_(i+1))
f''(x*) ≈ 2*d_012
```

Вывод содержит исходную таблицу, точку вычисления, использованные узлы, формулы и обе производные. [Демонстрационный вывод для `y=x²`](results/4_example.txt): при `x*=0.5` получаются `f'=1`, `f''=2`. Для варианта 14 результат появится после получения его таблицы.
