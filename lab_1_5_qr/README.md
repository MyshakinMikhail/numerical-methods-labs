# Лабораторная 1.5 — QR-разложение и QR-алгоритм

QR-разложение строится отражениями Хаусхолдера. Для поиска собственных значений выполняются QR-итерации подобия. Вещественный блок `2×2` позволяет найти комплексно-сопряжённую пару по квадратному характеристическому уравнению.

```bash
python -m lab_1_5_qr.main lab_1_5_qr/input.json
python -m lab_1_5_qr.complex_example lab_1_5_qr/complex_input.json
```

Во втором запуске NumPy используется только для разрешённого сравнения с собственной реализацией. Основной QR-алгоритм от NumPy не зависит.

## Алгоритм

Отражение Хаусхолдера имеет вид `H=E-2vvᵀ` и зануляет элементы столбца под диагональю. Последовательность отражений даёт ортогональную `Q` и верхнетреугольную `R`.

Для собственных значений выполняется итерация `A(k+1)=R(k)Q(k)`, являющаяся преобразованием подобия. Сдвиг ускоряет сходимость. Вещественная матрица с комплексной парой сходится не к диагональной, а к квазитреугольной форме с блоком `2×2`. Корни характеристического уравнения этого блока находятся через `cmath`, без NumPy.

JSON содержит `matrix`, `epsilon` и `max_iterations`. Выводятся `A`, `Q`, `R`, `Q·R`, ошибка восстановления, число итераций, квазитреугольная матрица и собственные значения.

## Вопросы для защиты

1. **Почему `Q` ортогональна?** Каждое отражение ортогонально, а произведение ортогональных матриц тоже ортогонально.
2. **Почему QR-итерация сохраняет спектр?** Если `A=QR`, то `RQ=QᵀAQ`, то есть это преобразование подобия.
3. **Зачем нужен сдвиг?** Он ускоряет отделение собственного значения и уменьшение поддиагонального элемента.
4. **Почему результат может быть не диагональным?** Комплексная пара вещественной матрицы представляется вещественным блоком `2×2`.
5. **Где используется NumPy?** Только в `complex_example.py` для сравнения; `qr.py` полностью самостоятельный.
