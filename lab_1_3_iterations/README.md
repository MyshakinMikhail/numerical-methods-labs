# Лабораторная 1.3 — простые итерации и метод Зейделя

Оба метода приводят систему к виду `x=β+αx`, начинают с одного приближения и останавливаются при `||x(k)-x(k-1)||∞ ≤ ε`.

```bash
python -m lab_1_3_iterations.main lab_1_3_iterations/input.json
```

Метод простых итераций вычисляет весь новый вектор по предыдущему. Метод Зейделя сразу использует уже найденные компоненты нового приближения. Условие `||α||∞<1` является достаточным условием сходимости. Эталон находится собственной LUP-реализацией.

## Формат и результат

JSON содержит `matrix`, `rhs`, `epsilon`, `max_iterations` и необязательный `initial_guess`. Если начального приближения нет, используется нулевой вектор.

Программа выводит норму матрицы итераций, оба решения, число итераций, норму последнего изменения, невязку, эталон LUP и фактическую ошибку. Ограничение итераций защищает от бесконечного цикла при расходящемся процессе.

## Вопросы для защиты

1. **Как получить `α` и `β`?** Каждая строка делится на диагональный элемент, диагональная неизвестная остаётся слева, остальные переносятся вправо.
2. **Чем Зейдель отличается от простых итераций?** Он сразу использует уже обновлённые компоненты текущей итерации.
3. **Что гарантирует сходимость?** Например, `||α||<1` или строгое диагональное преобладание — достаточные, но не необходимые условия.
4. **Как выбран момент остановки?** `||x(k)-x(k-1)||∞≤ε`; дополнительно выводится невязка.
5. **Зейдель всегда быстрее?** Нет, но часто требует меньше итераций благодаря немедленному использованию новых значений.
