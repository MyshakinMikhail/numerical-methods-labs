# Лабораторная работа 2 — вариант 14

В обоих пунктах реализованы методы простой итерации и Ньютона. Точность `epsilon`, предел числа итераций и начальное приближение задаются в JSON. Программы выводят приближения на каждом шаге, погрешность относительно решения Ньютона с точностью `1e-14`, число итераций и невязку.

## 2.1. Нелинейное уравнение

Решается `x³ − 2x² − 10x + 15 = 0`. [График](graphs/equation.svg) показывает два положительных корня; выбран меньший, из интервала `(1.3, 1.4)`. Начальное приближение `x₀ = 1.4`. Для простой итерации используется `xₖ₊₁ = (xₖ³ − 2xₖ² + 15)/10`; на этом интервале модуль производной итерационной функции меньше 1.

При `epsilon = 1e-8` результат: `x ≈ 1.38196601125`. Простая итерация сделала 5 шагов, Ньютон — 3. Погрешность простой итерации уменьшилась с `1.80e-2` до `7.21e-11`, у Ньютона — до машинного нуля. Вблизи корня первая последовательность убывает приблизительно геометрически, а метод Ньютона сходится быстрее.

## 2.2. Система нелинейных уравнений

При `a = 3` система имеет вид:

```text
x₁²/9 + x₂²/2.25 − 1 = 0,
3x₂ − exp(x₁) − x₁ = 0.
```

На [графике](graphs/system.svg) пересечение кривых с положительными координатами находится около `(1.1, 1.4)`. Начальное приближение `(1.0, 1.2)`. Простая итерация обновляет `x₁` как `x₁ − 0.5·f₁(x₁, x₂)`, затем вычисляет `x₂ = (exp(x₁) + x₁)/3`; коэффициент `0.5` даёт сжатие в окрестности выбранного пересечения. Метод Ньютона решает линейную систему с якобианом на каждом шаге.

При `epsilon = 1e-8` результат: `(x₁, x₂) ≈ (1.11780971539, 1.39198612064)`. Простая итерация сделала 7 шагов, Ньютон — 4. Максимальная погрешность координат уменьшилась соответственно с `1.92e-1` до `2.70e-11` и до машинной точности.
