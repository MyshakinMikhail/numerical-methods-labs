# Лабораторная работа 2 — вариант 14

В обоих пунктах реализованы методы простой итерации и Ньютона. Точность `epsilon`, предел числа итераций и начальное приближение задаются в JSON. Программы выводят приближения на каждом шаге, погрешность относительно решения Ньютона с точностью `1e-14`, число итераций и невязку.

## 2.1. Нелинейное уравнение

Решается `x³ − 2x² − 10x + 15 = 0`. [График функции](graphs/equation.png) показывает два положительных корня и увеличенный участок с выбранным интервалом `[1.3, 1.4]`. На нём отмечены границы, начальное приближение `x₀ = 1.4` и меньший положительный корень. Для простой итерации используется `xₖ₊₁ = (xₖ³ − 2xₖ² + 15)/10`; на этом интервале модуль производной итерационной функции меньше 1.

При `epsilon = 1e-8` результат: `x ≈ 1.38196601125`. Простая итерация сделала 5 шагов, Ньютон — 3. Погрешность простой итерации уменьшилась с `1.80e-2` до `7.21e-11`, у Ньютона — до машинного нуля. Вблизи корня первая последовательность убывает приблизительно геометрически, а метод Ньютона сходится быстрее.

[График погрешности](graphs/equation_convergence.png) сравнивает оба метода по величине `eₖ = |x⁽ᵏ⁾ − x_ref|`. Последняя погрешность Ньютона относительно более точного опорного корня составляет примерно `5.43e-17`; ноль в таблице программы означает совпадение с её опорным решением в арифметике `float`.

## 2.2. Система нелинейных уравнений

При `a = 3` система имеет вид:

```text
x₁²/9 + x₂²/2.25 − 1 = 0,
3x₂ − exp(x₁) − x₁ = 0.
```

На [графике кривых](graphs/system.png) отмечены начальное приближение `(1.0, 1.2)` и найденное пересечение с положительными координатами. Простая итерация обновляет `x₁` как `x₁ − 0.5·f₁(x₁, x₂)`, затем вычисляет `x₂ = (exp(x₁) + x₁)/3`; коэффициент `0.5` обеспечивает локальную сходимость этой последовательности. Метод Ньютона решает линейную систему с якобианом на каждом шаге.

При `epsilon = 1e-8` результат: `(x₁, x₂) ≈ (1.11780971539, 1.39198612064)`. Простая итерация сделала 7 шагов, Ньютон — 4. Максимальная погрешность координат уменьшилась соответственно с `1.92e-1` до `2.70e-11` и до машинной точности.

[График погрешности](graphs/system_convergence.png) сравнивает методы по величине `eₖ = max(|x₁⁽ᵏ⁾ − x₁_ref|, |x₂⁽ᵏ⁾ − x₂_ref|)`.

Графики погрешности используют историю исходных программ, включая начальную точку `k = 0`. Вертикальная шкала логарифмическая; красная пунктирная линия показывает `epsilon` из входного JSON. Опорные решения вычисляются с 80 десятичными цифрами: для 2.1 по формуле `(5 − √5)/2`, для 2.2 — после исключения `x₂` из второго уравнения. Это позволяет показывать последние ошибки без округления до нуля. Эти опорные значения нужны для анализа; критерии остановки исходных методов остаются прежними.

Программы останавливаются, когда одновременно малы шаг и невязка. Поэтому пересечение линией погрешности уровня `epsilon` может произойти раньше последней итерации. Малый шаг, невязка и погрешность относительно корня — разные величины.

## План разбора для сдачи

1. **Условие 2.1 и 2.2.** Что считаем корнем уравнения и решением системы, какие положительные решения требуется найти.
2. **Исходные графики.** Почему корень 2.1 — пересечение с осью `x`, а решение 2.2 — пересечение двух кривых. Как выбираем интервал, начальную точку и проверяем знаки на границах.
3. **Простая итерация.** Как получаем форму `x = φ(x)`, подставляем текущее приближение и выбираем сходящуюся формулу. Разница между одним числом и парой координат.
4. **Ньютон для уравнения.** Вывод через линейную часть формулы Тейлора: `f(x + Δx) ≈ f(x) + f′(x)·Δx`, отсюда `x_new = x − f(x)/f′(x)`. Один численный шаг.
5. **Ньютон для системы.** Частные производные и якобиан; линеаризация `F(x) + J(x)·Δx ≈ 0`, решение `J(x)·Δx = −F(x)`, обновление координат. Один численный шаг.
6. **Точность и остановка.** Погрешность, разность соседних приближений и невязка; какие проверки выполняют наши программы и почему важна близость начального приближения к решению.
7. **Графики погрешности.** Что означают оси, `k = 0`, две линии и уровень `ε`; как считаем каждую точку. Почему простая итерация обычно имеет линейную сходимость, а Ньютон около простого корня — квадратичную. Сравнить наши результаты: 5 и 3 шага в 2.1, 7 и 4 в 2.2; объяснить, почему пересечение уровня `ε` и остановка могут не совпадать.
8. **Короткий рассказ на сдаче.** Условие → график и начальное приближение → формулы методов → контроль остановки → результат и сравнение сходимости.
