# Лабораторные работы по численным методам

Пять заданий первой лабораторной работы. Реализации написаны на чистом Python без NumPy: каждый пункт лежит в одном файле, общие короткие операции вынесены в `common.py`, исходные данные — в `inputs`.

## Состав

| Файл | Метод |
|---|---|
| `lab1_lu.py` | LUP-разложение с выбором главного элемента, решение СЛАУ, обратная матрица и определитель |
| `lab2_thomas.py` | метод прогонки для трёхдиагональной СЛАУ |
| `lab3_iterations.py` | методы простых итераций и Гаусса—Зейделя |
| `lab4_jacobi.py` | собственные значения и векторы методом вращений Якоби |
| `lab5_qr.py` | QR-разложение Хаусхолдера и QR-алгоритм поиска собственных значений |

## Запуск

Требуется Python 3.10 или новее. Внешние библиотеки не нужны.

```bash
python3 lab1_lu.py
python3 lab2_thomas.py
python3 lab3_iterations.py
python3 lab4_jacobi.py
python3 lab5_qr.py
```

Путь к другому JSON можно передать первым аргументом, например:

```bash
python3 lab5_qr.py inputs/5_complex.json
```

Проверки:

```bash
python3 -m unittest -v tests
```

## Что проверяется в выводе

- Для LUP: равенство `L·U = P·A`, невязка решения и `A·A⁻¹ = E`.
- Для прогонки: коэффициенты `α`, `β` и невязка.
- Для итерационных методов: итерационная форма `x = β + αx`, число итераций и невязка обоих методов.
- Для вращений Якоби: равенство `A·V = V·Λ`.
- Для QR: равенство `Q·R = A` и собственные значения итоговой квазитреугольной матрицы. Поддерживаются вещественные и комплексно-сопряжённые пары.
