# Лабораторные работы по численным методам

Пять лабораторных работ варианта 14 на Python. Матрицы, правые части и параметры читаются из JSON-файлов; размерности не зафиксированы в исходном коде. Все основные численные методы реализованы самостоятельно.

## Требования

- Python 3.11 или новее.
- Основные программы используют только стандартную библиотеку.
- NumPy необязателен и нужен только для разрешённого сравнения комплексных собственных значений в лабораторной 1.5.

При необходимости установить NumPy:

```bash
python -m pip install -r requirements.txt
```

## Структура

- `common` — чтение JSON, проверки, печать и элементарные операции с матрицами;
- `lab_1_1_lu` — LUP-разложение, решение, обратная матрица и определитель;
- `lab_1_2_thomas` — метод прогонки с хранением только трёх диагоналей;
- `lab_1_3_iterations` — простые итерации и метод Зейделя;
- `lab_1_4_jacobi_rotation` — собственные пары симметричной матрицы;
- `lab_1_5_qr` — QR-разложение и собственные значения произвольной вещественной матрицы.

## Запуск

Все команды выполняются из каталога `numerical_methods`:

```bash
python -m lab_1_1_lu.main lab_1_1_lu/input.json
python -m lab_1_2_thomas.main lab_1_2_thomas/input.json
python -m lab_1_3_iterations.main lab_1_3_iterations/input.json
python -m lab_1_4_jacobi_rotation.main lab_1_4_jacobi_rotation/input.json
python -m lab_1_5_qr.main lab_1_5_qr/input.json
python -m lab_1_5_qr.complex_example lab_1_5_qr/complex_input.json
```

Если путь не передан, каждая программа читает свой `input.json`.

## Тесты

```bash
python -m unittest discover -v
```

Тесты проверяют математические тождества, невязки, другие размерности и основные ошибочные входы. NumPy для основного набора тестов не нужен.
