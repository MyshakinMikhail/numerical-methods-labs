# Лабораторная 1.4 — метод вращений Якоби

Метод применяется к вещественным симметричным матрицам. На каждом шаге зануляется максимальный по модулю внедиагональный элемент, а произведение всех вращений образует матрицу собственных векторов.

```bash
python -m lab_1_4_jacobi_rotation.main lab_1_4_jacobi_rotation/input.json
```

Угол выбирается по формуле `φ = 1/2·atan2(2a_pq, a_pp-a_qq)`. Остановка происходит при норме внедиагональной части не больше `ε`. Проверка выполняется равенством `A·V≈V·Λ`.

## Алгоритм и результат

Метод допустим только для вещественной симметричной матрицы. В каждой итерации выбирается максимальный по модулю элемент выше диагонали. Ортогональное преобразование подобия зануляет его и сохраняет собственные значения. Матрица `V` начинается с единичной и умножается на каждое вращение.

Программа сортирует собственные значения и согласованно переставляет столбцы `V`. Выводятся `λ_i`, векторы `h_i`, `V`, `Λ`, `A·V`, `V·Λ` и ошибка равенства.

## Вопросы для защиты

1. **Почему матрица должна быть симметричной?** Тогда все собственные значения вещественны, а собственные векторы можно выбрать ортонормированными.
2. **Почему выбирается максимальный элемент?** Его зануление быстрее уменьшает общую внедиагональную норму.
3. **Что сохраняет преобразование?** Ортогональное подобие `A'=UᵀAU` сохраняет собственные значения.
4. **Откуда берутся собственные векторы?** Это столбцы произведения всех матриц вращения.
5. **Когда алгоритм останавливается?** Когда евклидова норма всех внедиагональных элементов не превышает `ε`.
