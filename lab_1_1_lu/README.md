# Лабораторная 1.1 — LUP-разложение

Реализовано разложение `P·A = L·U` с частичным выбором максимального по модулю опорного элемента. Из одного разложения находятся решение, обратная матрица и определитель.

```bash
python -m lab_1_1_lu.main lab_1_1_lu/input.json
```

Формат JSON: квадратная `matrix` и вектор `rhs` той же длины. Файл `lu.py` содержит алгоритм, а `main.py` отвечает только за чтение и отчёт.

Определитель равен произведению диагональных элементов `U`, умноженному на `(-1)^s`, где `s` — число перестановок строк. Обратная матрица составляется из решений `A·x=e_i`.

## Алгоритм

На шаге `k` среди строк `k..n-1` выбирается строка с максимальным `|a_ik|`. Перестановка применяется к `U`, `P` и уже заполненной части `L`. После исключения элементов под диагональю система решается двумя подстановками: сначала `L·y=P·b`, затем `U·x=y`.

Сложность разложения — `O(n³)`, одной пары подстановок — `O(n²)`.

## Что выводится

`L`, `U`, `P`, обе части `L·U=P·A`, решение, невязка, `A⁻¹`, проверка `A·A⁻¹=E` и определитель.

## Вопросы для защиты

1. **Зачем выбирать опорный элемент?** Чтобы избежать деления на ноль и уменьшить влияние округлений.
2. **Почему появляется `P`?** Она хранит все перестановки строк исходной матрицы.
3. **Почему диагональ `L` равна единице?** Множители исключения записываются ниже диагонали, а единицы соответствуют принятой форме разложения Дулиттла.
4. **Как найти определитель?** Перемножить диагональ `U` и изменить знак при нечётном числе перестановок.
5. **Как находится обратная матрица?** Решаются системы `A·x=e_i`, а решения становятся столбцами `A⁻¹`.
