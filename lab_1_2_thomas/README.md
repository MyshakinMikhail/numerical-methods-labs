# Лабораторная 1.2 — метод прогонки

Алгоритм принимает только нижнюю, главную и верхнюю диагонали, поэтому использует `O(n)` памяти. Плотная матрица не создаётся даже при проверке невязки.

```bash
python -m lab_1_2_thomas.main lab_1_2_thomas/input.json
```

Для строки `i` прямого хода:

```text
denominator_i = b_i + a_i·α_(i-1)
α_i = -c_i / denominator_i
β_i = (d_i - a_i·β_(i-1)) / denominator_i
```

На обратном ходу используется `x_i = α_i·x_(i+1) + β_i`.

## Формат входа

Для системы размера `n`: `lower` и `upper` имеют длину `n-1`, а `diagonal` и `rhs` — длину `n`. Файл `thomas.py` нигде не создаёт массив `n×n`.

Метод требует ненулевых знаменателей прямого хода. Достаточное практическое условие устойчивости — диагональное преобладание трёхдиагональной матрицы.

## Что выводится

Все коэффициенты `α_i`, `β_i`, решение и бесконечная норма невязки, вычисленная непосредственно по диагоналям.

## Вопросы для защиты

1. **Для каких систем применим метод?** Для трёхдиагональных СЛАУ при ненулевых знаменателях прогонки.
2. **Почему нельзя хранить всю матрицу?** Ненулевы только три диагонали; плотное хранение расходует `O(n²)` вместо `O(n)` памяти.
3. **Что означают `α` и `β`?** Это коэффициенты представления `x_i=α_i x_(i+1)+β_i`.
4. **Почему есть два хода?** Прямой ход строит коэффициенты, обратный восстанавливает неизвестные с конца.
5. **Какова сложность?** `O(n)` времени и `O(n)` памяти.
